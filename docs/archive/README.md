# Archived planning documents

These files record how CryoQuant was designed and built (phases, ADRs, module inventory, glue-layer plan). They are **not** required to use the framework.

For day-to-day work, start with [how_to_use.md](../how_to_use.md).

| File | What it was |
|---|---|
| [quant_plan.md](quant_plan.md) | High-level phase plan and repository layout |
| [quant_spec.md](quant_spec.md) | Per-phase implementation spec and acceptance tests |
| [FRAMEWORK_STATUS.md](FRAMEWORK_STATUS.md) | Living module inventory (snapshot at archive time) |
| [workflow_plan.md](workflow_plan.md) | Workflow glue layer design (`align`, `resolve`, `panel`, `fit_loop`) |
| [decisions.md](decisions.md) | Architecture decision log (D1–D24) |
